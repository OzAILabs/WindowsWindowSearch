How we cut our LLM bill by 40%

Priya Raman · Infrastructure

Our support assistant was spending most of its budget repeating itself. Every request carried the same long instructions, so we were paying full token cost for text the model had already seen thousands of times.

Cache what doesn't change

Moving the fixed instructions to the start of each prompt let the provider cache them. That one change lowered the average cost per request by 27%.

prompt = cached(instructions) + retrieved_docs + question
# before: 4,200 tokens at full price
# after:  3,800 tokens cached, 400 at full price

Send less context

We also stopped attaching whole documents. Retrieving only the three most relevant passages cut input tokens by a third with no measurable drop in answer quality.
