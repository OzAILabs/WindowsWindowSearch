Windows Window Search

Find any open window or browser tab by searching its title or the text inside it, see a preview, and jump straight to it.

Ctrl+Alt+Space opens the search

Getting started

Windows Window Search runs quietly in the notification area (next to the clock). It remembers what each window and Edge tab showed when you last looked at it, so you can find it again later.

1

Open the search

Press Ctrl+Alt+Space anywhere, or click the magnifier icon in the notification area.

2

Type what you remember

A few words from the page, the tab title, the site or the app, such as token cost.

3

Press Enter

The window comes to the front, restored if it was minimized, and Edge switches to the right tab.

  • Searches inside pagesPage text of Edge tabs, documents, mail and most other apps, not just titles.
  • Real previewsScreenshots saved as you use windows, so even minimized Edge windows aren't blank.
  • Most recent firstWith nothing typed, the list shows windows and tabs in the order you last used them.
  • Stays on your PCNothing is uploaded. The index lives in your own user profile.
First runThe app learns as you work. A window becomes searchable by its text the first time you look at it after the app starts. To catch up on Edge tabs you haven't opened yet, use Scan Edge tabs.

Moving and resizing

Drag the shaded title bar at the top (the pointer turns into a four-way arrow) to move the window, for example onto another screen. The status line at the bottom works too. The × at the top right closes it, like Esc. Drag any edge or corner to resize it. It opens where you left it, at the size you chose. If that screen is disconnected, it opens centered on the screen with the mouse pointer. To go back to the default, use Settings → Search window → Reset size and position.

Grid view

Press Tab to switch between the list and a grid of large previews, which is handy when you remember what a window looked like. Typing filters the grid the same way. The tray menu's Open grid view opens straight into it.

How search works

Type a few words. Every word has to match somewhere, but it doesn't have to be the whole word.

You typeIt finds
token costPages containing both words, including tokens and costs. Word order doesn't matter.
adm devWord beginnings work: admin and devices.
excel budgetApp names count, so this finds the Excel window with budget in its title.
techcrunchSite names and addresses of Edge tabs.
bdgt rvwTitles also match loosely (fuzzy), so a rough spelling still finds Budget review.

What gets indexed

  • Titles of every window and every Edge tab, always.
  • Page text of each Edge tab, read when you view it.
  • Text in other apps (Word, Outlook, Teams, File Explorer and most others), read through Windows accessibility.
  • Text in screenshots (built-in Windows OCR) for apps that don't expose their text and for sites set to screenshot only.

Results are ranked by how well they match, then by how recently you used them.

Search shows what a window showed when you last looked at itIf a page changed while it was in the background, the new text becomes searchable the next time you bring it up. Unchanged pages are re-read every couple of minutes while you work in them.

Edge tabs and tab scan

Edge only lets other apps read the tab that's currently showing in each window. So a tab's text becomes searchable the first time you view it, and stays searchable after that, even when Edge puts the tab to sleep.

Scan Edge tabs you haven't viewed

Tabs you haven't opened since the app started match by title only (not viewed yet). To fill them in, choose Scan Edge tabs missing text or preview… from the tray menu, or click the scan link in the search window's status line. The app then:

  1. tells you how many tabs it will scan and roughly how long it will take, and waits for you to click OK;
  2. switches through those tabs, several windows at a time, saving each tab's text and a preview;
  3. briefly shows minimized Edge windows without taking focus so their tabs get a preview, then minimizes them again;
  4. puts every window back on the tab you had open, and shows a summary.
Hands off while it runsAny key press or mouse movement stops the scan right away and restores your tabs. You can also stop it from the tray menu. Tabs that were asleep use more memory for a while after the scan, until Edge puts them back to sleep.

Closed tabs

When you close a tab, its text stays searchable for 7 days (you can change this). It shows as closed tab, and Enter reopens its address in Edge.

InPrivate windows

InPrivate windows are listed by title but aren't read or captured, unless you turn on Include InPrivate windows in the tray menu or Settings. That's useful if you use InPrivate for a second sign-in, such as an admin account, but it keeps a local record of those pages.

Settings are stored in %LOCALAPPDATA%\WindowSearcher\settings.json. Open settings file in the Settings window opens it for direct editing; changes apply as soon as the file is saved.

Privacy and your data

  • Nothing leaves your PC. The app makes no network connections. The index, previews, settings and log are stored in %LOCALAPPDATA%\WindowSearcher, in your own profile and outside OneDrive.
  • Password fields are never read. Password managers are excluded by default.
  • InPrivate windows are skipped unless you choose to include them.
  • Old data expires. Text from closed windows is removed, and closed tabs are deleted after the retention period.
  • You're in control. Exclude apps and sites in Settings, pause indexing at any time, or wipe everything with Clear index and previews.

Uninstalling the app keeps your data folder, so reinstalling picks up where you left off. Delete %LOCALAPPDATA%\WindowSearcher to remove it.

Troubleshooting

Pressing the shortcut does nothing

Check the notification area for the magnifier icon. If it isn't there, start Windows Window Search from the Start menu. If another app already uses Ctrl+Alt+Space, a notification says so when the app starts; choose a different shortcut in Settings.

The search window is too big or on the wrong screen

Drag its edges to resize it, and drag the shaded title bar at the top to move it. It remembers the new size and place. The first time it opens, it's sized to fit the screen, and it's never larger than the screen it opens on.

A tab I know about only matches by its title

Its text hasn't been read yet. It shows not viewed yet. View the tab once, or run Scan Edge tabs from the tray menu.

The preview is missing or out of date

A preview is saved each time a window is on screen. Windows that have been minimized since the app started have none until you open them, or until a tab scan briefly shows them. Bring the window up once and the preview is saved.

The tab scan stopped early

Any key press or mouse movement stops the scan on purpose, so it never fights you for the screen. Start it again and leave the PC alone until the summary appears. Tabs listed as didn't load took longer than the time limit; you can raise it under Settings → Tab scan.

A web page flickers while the app is running

Reading a page switches on Edge's accessibility support, and a few sites redraw oddly while it's on. Add the site to Sites indexed by screenshot only in Settings. admin.example.com is on that list by default.

An app feels slow while the app is running

Apps that respond slowly are detected automatically and switched to screenshot-only reading. You can also add an app to Apps never captured or read, or pause indexing from the tray menu.

Search results look wrong or stale

Use tray menu → Clear index and previews… to start fresh. Open windows are indexed again as you use them.

Reporting a problem

Tray menu → Open log, and send the log along with a short description to OzAILabs on GitHub.

For administrators

The MSI installs per machine to C:\Program Files\Windows Window Search and adds Start menu shortcuts. The app is self-contained, so no .NET runtime is needed. Each user's data stays in their own profile.

TaskCommand
Silent installmsiexec /i WindowsWindowSearch-<version>-x64.msi /qn /norestart
Silent uninstallmsiexec /x <product code> /qn /norestart
DetectionC:\Program Files\Windows Window Search\WindowSearcher.exe, file version

Installing a newer MSI upgrades in place, and an older one can be installed over a newer one to roll back. The installer closes a running copy of the app before replacing its files.
